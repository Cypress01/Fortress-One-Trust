# Fortress One Trust LLC - Website

Professional fiduciary and wealth management services website built with modern HTML, CSS, and vanilla JavaScript.

## 📋 Overview

Fortress One Trust LLC is a boutique financial services firm specializing in personalized trust administration, wealth management, and fiduciary services for individuals, families, and businesses in Indiana.

## 🚀 Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Reveal-on-scroll animations for engaging user experience
- **Professional Typography**: Custom font pairing (EB Garamond + Lato)
- **Accessibility**: Semantic HTML and ARIA labels for inclusive design
- **Modern Layout**: CSS Grid and Flexbox for clean, flexible layouts
- **Performance**: Lazy loading images, optimized assets

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. Clone or download this repository
2. Navigate to the project folder
3. Open `src/index.html` in a web browser

### Local Development

For development with live reload, use any local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000/src/`

## 📝 Customization

### Updating Content

Edit `src/index.html` to modify:

- Company information
- Contact details
- Services descriptions
- Team information

### Styling

Modify `src/styles.css` to:

- Change colors via CSS variables (`:root`)
- Adjust spacing and sizing
- Customize fonts and typography
- Update animations and transitions

### Images

Place images in the `assets/` folder and reference them in HTML:

```html
<img src="../assets/your-image.jpg" alt="Description" />
```
